Project: Child-Prolog Lab

A child-understandable Prolog system that explains symbolic reasoning through animated examples, recursive compression, grammar generation, graph transformation, Spec-to-Algorithm, Gaussian discovery, and web visualization.

1. Goal

Build a small educational Prolog + JavaScript system where a child can type simple logical rules and see:

* what the rule means,
* how recursion unfolds,
* how repeated patterns compress,
* how a grammar generates stories,
* how graphs transform,
* how formulas are discovered,
* how a specification becomes an algorithm.

The system should run in the browser using JavaScript, with a Prolog-like engine or a Prolog-to-JS layer.

Requirement

Create a tiny JavaScript Prolog-style interpreter supporting:

* facts,
* rules,
* variables,
* unification,
* recursive calls,
* trace collection,
* JSON output for visualization.

Example

Input:

parent(alice,bob).
parent(bob,charlie).
ancestor(X,Y) :- parent(X,Y).
ancestor(X,Y) :- parent(X,Z), ancestor(Z,Y).

Query:

ancestor(alice,charlie).

Child explanation:

Alice is Charlie's ancestor because:
1. Alice is Bob's parent.
2. Bob is Charlie's parent.
3. So Alice is connected to Charlie through Bob.

5. Stage 2 — Recursive Compression

Requirement

Show recursion as an expandable/compressible tree.

Example file:

sum_to(0,0).
sum_to(N,Sum) :-
  N > 0,
  N1 is N - 1,
  sum_to(N1,Prev),
  Sum is N + Prev.

Query:

sum_to(5,S).

Expected explanation:

sum_to(5) means:
5 + sum_to(4)
5 + 4 + sum_to(3)
5 + 4 + 3 + sum_to(2)
5 + 4 + 3 + 2 + sum_to(1)
5 + 4 + 3 + 2 + 1 + 0
So the answer is 15.

Compression explanation:

The repeated idea is: keep adding the next smaller number.
This compresses to:
S = N(N+1)/2

Formula:

sum_to(N) = N * (N + 1) / 2

The robot finds a dragon.
A dragon builds the robot.

Child explanation:

A sentence is made from:
1. a noun phrase
2. a verb phrase
A noun phrase is:
1. a determiner

7. Stage 4 — Gaussian Elimination for Recursive Discovery

Requirement

Given a sequence, infer a polynomial rule using finite differences or Gaussian elimination.

Example input:

discover_formula([1,4,9,16,25], Formula).

Expected output:

Formula: N^2

Explanation:

The numbers are:
1, 4, 9, 16, 25
First differences:
3, 5, 7, 9
Second differences:
2, 2, 2
Because the second difference is constant, the rule is quadratic.
The discovered rule is:
a(N) = N^2

Working examples:

[1, 2, 3, 4, 5]       → N
[1, 4, 9, 16, 25]     → N^2
[1, 8, 27, 64, 125]   → N^3
[2, 4, 6, 8, 10]      → 2N
[3, 6, 11, 18, 27]    → N^2 + 2

8. Stage 5 — Graph Transformations

Requirement

Represent graphs as facts and animate transformations.

Example:

node(a).
node(b).
node(c).
edge(a,b).
edge(b,c).
rule(connect_grandparent) :-
  edge(X,Y),
  edge(Y,Z),
  add_edge(X,Z).

Query:

apply(connect_grandparent).

Before:

a → b → c

After:

a → b → c
a → c

Child explanation:

Because A connects to B, and B connects to C,
we can add a shortcut from A to C.

Applications:

* family trees,
* maps,
* transport networks,
* proof dependency graphs,
* grammar derivation trees,
* symbolic transformations.

9. Stage 6 — Spec-to-Algorithm

Requirement

Allow a child to write a plain-language-like specification and generate simple logic.

Example spec:

Find the biggest number in a list.

Generated child Prolog:

biggest([X], X).
biggest([X|Rest], Biggest) :-
  biggest(Rest, RestBiggest),
  max(X, RestBiggest, Biggest).

Explanation:

To find the biggest number:
1. If the list has one number, that number is biggest.
2. Otherwise, find the biggest number in the rest of the list.
3. Compare the first number with that result.

Visualization:

[3, 8, 2, 5]
compare 3 with biggest([8,2,5])
compare 8 with biggest([2,5])
compare 2 with biggest([5])
answer = 8

function runExample() {
  const output = document.getElementById("output");
  const steps = [
    "sum_to(5) = 5 + sum_to(4)",
    "sum_to(4) = 4 + sum_to(3)",
    "sum_to(3) = 3 + sum_to(2)",
    "sum_to(2) = 2 + sum_to(1)",
    "sum_to(1) = 1 + sum_to(0)",
    "sum_to(0) = 0",
    "So: 5 + 4 + 3 + 2 + 1 + 0 = 15",
    "Compressed rule: N(N+1)/2"
  ];
  output.innerHTML = `
    <h2>Answer: S = 15</h2>
    <h3>Explanation</h3>
    ${steps.map(s => `<div class="step">${s}</div>`).join("")}
    <h3>Visual Compression</h3>
    <svg width="400" height="120">
      <text x="10" y="30">5 + 4 + 3 + 2 + 1</text>
      <text x="10" y="70">↓ compresses to ↓</text>
      <text x="10" y="110">N(N+1)/2</text>
    </svg>
  `;
}

15. Core Innovation

The novel angle is:

Prolog is not just used to compute answers; it is used to make reasoning visible.

This makes the system useful for:

* children learning logic,
* visual theorem discovery,
* symbolic AI education,
* recursive algorithm explanation,
* Spec-to-Algorithm systems,
* semantic visualization,
* and future proof assistants that explain why a conclusion follows.
